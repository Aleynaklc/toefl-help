TOEFL Vocab Projesi

Bu proje React (Vite) kullanılarak geliştirilmiştir. Tarayıcılar React (JSX) kodunu doğrudan okuyamadığı için uygulamanın derlenmesi (build) gerekir.

Projeyi GitHub Pages üzerinden otomatik yayınlamak (publish) için GitHub'da Settings > Pages menüsüne gidip kaynağı GitHub Actions olarak seçmeniz yeterlidir. Sizin için gerekli otomatik yayınlama dosyasını (deploy.yml) projeye ekledim.
